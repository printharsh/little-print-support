# Little Print support page

Static, responsive privacy and beta-support page for the simplified **1.1 (2)** iPhone app and Photos share extension. `index.html` is the deployable source; it uses no JavaScript, external fonts, or external assets.

The notice describes local photo processing, Bluetooth printing, same-phone App Group history/preferences, explicit exports, Apple/TestFlight services, and deletion limits. It does not advertise removed creative-camera or shared-cloud features.

Current intended URL: https://printharsh.github.io/little-print-support/

Changes in this workspace are not automatically published. The release owner must deploy the updated page and check the live URL before distribution. This support URL is not a TestFlight installation link. No personal contact details are embedded.
